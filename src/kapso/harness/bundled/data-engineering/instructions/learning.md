# Learning

Scope every lesson by the stack (engine, transformation tool, orchestrator), the layer
(source, staging, intermediate, mart, snapshot, load) and the mechanism. A lesson states
the revealing query or the invariant that found the cause and the shape of the fix, with
the attempt as evidence; a ticket whose premise was wrong is a lesson about the reference,
not about the pipeline; never this project's dataset names, columns or numbers as facts
for the next ticket.
