# Learning

Scope every lesson by the task family, the model class and size, the runner's plug-in
point and the failure class it addressed. A lesson states the component that moved the
pass count, by how much, on how many tasks and trials, for which model, with the attempt
as evidence, and the condition under which it should be retired; never this task set's
documents, tool names, repositories or customers as facts for the next task. A component
that stopped earning its place, shown by the re-ablation when a later component overlapped
its failure class, is a lesson too.
