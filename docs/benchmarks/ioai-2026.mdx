The [International Olympiad in Artificial Intelligence](https://ioai-official.org) is the IMO of the AI era. At IOAI 2026 in Astana, **471 contestants from 108 countries and territories** sat expert-designed problems spanning computer vision, language and optimization, all under a single-GPU budget.

In 2026 the olympiad opened a second arena. [IOAI², the AI Model Track](https://ioai-official.org/ai-model-track/), puts AI systems in the same exam hall: the same [six contest tasks](https://github.com/IOAI-official/IOAI-2026), **two unattended six-hour sessions** of three tasks each, up to 50 submission attempts per task, every solution scored on standardized single-GPU hardware.

Once a session starts, no human may solve, correct, or improve anything. Fourteen AI labs entered as Founding AI Participants. Kapso was one of them. The olympiad's own account of the inaugural track: [the organizers' write-up of the AI Model Track's first edition](https://ioai-official.org/what-happens-when-autonomous-ai-takes-on-the-same-tasks-as-the-worlds-top-young-ai-talents/)

The scores are the organizers': every submission was scored on the track's standardized single-GPU
hardware during the two unattended six-hour sessions of IOAI 2026 in Astana, and the totals are the
olympiad's published results for the AI Model Track. Kapso's sessions were launched by Leeroo and ran
without human input, as the track requires; the contest sessions' own records are not in
this repository. The runner as it ships (below) routes every submission through the task root's
procedure, which records it in the campaign's ledger (the procedure and the organizers' rules are in
the [benchmark directory](https://github.com/Leeroo-AI/kapso/tree/main/benchmarks/ioai2026)).

## How Kapso runs it

Three stages, with the campaign clock starting at brief-in.

1. **Preflight.** One agent session ingests the official task brief, downloads the data, and writes the task statement.
2. **Campaign.** The experimentation — ideation, implementation, judged feedback — runs in parallel lanes. Each lane cycles submit-and-learn rounds through the official submission system: predict the score, submit, bank the result, study the gap, go again.
3. **Shared learning.** Lanes learn from every sibling submission on the board, and ideas are grounded in a bank of past olympiad solutions served as experience: each card a past task's winning idea with its code, its score reported by others and marked so, promoted only once a campaign runs it.

The submit-and-learn cycle is what the format rewards. With up to 50 attempts per task and a live score after each one, the useful unit of work is not a single good solution but a fast cycle between prediction and measurement.

## Usage

```bash
pip install -e .
```

Ingest a task, from a URL or an organizer brief, into a run root, with the task's binding
rules (`--rules`; the default is the IOAI AI Models Track rules beside the script, and another
competition's rules file turns the preflight and the runner to that competition; a missing
rules file is refused):

```bash
PYTHONPATH=src:. python -m benchmarks.ioai2026.preflight \
    --task <task url or brief> --root tmp/ioai/task1 \
    --rules benchmarks/ioai2026/RULES.md
```

Run the campaign for one six-hour session:

```bash
PYTHONPATH=src:. python -m benchmarks.ioai2026.runner \
    --root tmp/ioai/task1 --hours 6
```

## Layout

| Path | Role |
|------|------|
| `context.py` / `submit.py` | The Brief from the preflight's statement / the submission procedure that records the ledger |
| `runner.py` | Campaign driver and staging |
| `preflight.py` | Task ingestion |
| `kernel_slots.py` | Ticket office over the submission platform's per-account session limits |

Full integration notes are in [`benchmarks/ioai2026/`](https://github.com/Leeroo-AI/kapso/tree/main/benchmarks/ioai2026).
