# Repo Memory

RepoMemory is the self-contained, high-level map of the exact workspace pinned
for one launch. It is rebuilt after the prepared-launch handoff and before paid
work, so its summary and table of contents describe the expert release, task
adapter, and starting artifacts actually visible to the coding agent.

RepoMemory is distinct from cross-run KnowledgeSnapshot:

- **RepoMemory** explains the current composed repository and where to work.
- **KnowledgeSnapshot** contains reviewed, cross-task claims, transfer episodes,
  contradictions, trust state, and semantic retrieval data pinned from GitHub.

The action prompt contains the complete RepoMemory representation. The pinned
knowledge snapshot remains behind the trusted prior reader; the provider can
only issue bounded list/get requests through its authenticated local relay.

The launch result records the RepoMemory digest alongside the launch, expert,
knowledge, and adapter identities. Resume revalidates those identities instead
of rebuilding startup state from a mutable source.
