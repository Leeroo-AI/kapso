# Production Orchestration

The production composer in `cross_run.launch.production_evolution` is the sole
public evolution orchestrator. It composes the existing launch, repository,
knowledge, workspace, action, and recovery services without introducing a
second state machine.

The required order is:

1. Resolve the typed config binding and repository authorities.
2. Resolve and materialize immutable expert, knowledge, security, adapter, and
   starting-artifact pins.
3. Validate and publish the prepared-launch handoff.
4. Rebuild RepoMemory from the composed workspace.
5. Open the pinned knowledge index and retrieve relevant prior records.
6. Install one durable sandboxed Codex edit action.
7. Reconcile its event lifecycle, validate provider termination and output,
   promote accepted edits, and create one direct-successor commit.
8. Return the complete identity set in result metadata.

Fresh runs require the full repository-free launch closure. Resume rejects that
closure and reuses the exact persisted launch and action identity. Repository
names and mutable GitHub references never enter a task request.

The coding agent receives a disposable `.git`-free source copy, a bounded local
prior relay, and only the configured provider egress. Trusted run controls,
GitHub/OpenAI credentials, Docker authority, host credential homes, prior packet
files, and audit files remain outside its namespace.
