## Overview

Kapso provides a CLI for running experiments without writing Python code.

## Basic Usage

```bash
kapso evolve --goal "Your problem description"
```

## Options

### Goal Specification

| Option | Short | Description |
|--------|-------|-------------|
| `--goal` | `-g` | Goal/problem description (inline) |
| `--goal-file` | `-f` | File containing goal description |

```bash
# Inline goal
kapso evolve --goal "Build a classifier for Iris dataset"

# From file
kapso evolve --goal-file problem.txt
```

### Basic Options

| Option | Short | Description |
|--------|-------|-------------|
| `--output` | `-o` | Required durable run root |
| `--config` | | Runtime config with cross-run repository bindings |
| `--launch-inputs` | | Required fresh-launch JSON; forbidden with `--resume` |
| `--resume` | | Continue the exact persisted launch and action |

```bash
kapso evolve --goal "..." --output ./runs/task-001 \
  --config ./runtime.yaml --launch-inputs ./launch-inputs.json
```

### Configuration Options

| Option | Short | Description |
|--------|-------|-------------|
| `--mode` | `-m` | Configuration mode and typed domain binding |
| `--coding-agent` | `-a` | Must be `codex` and match the pinned authority |
| `--scope-id` | | Exact scope binding override |
| `--task-family-id` | | Exact task-family binding override |
| `--task-adapter-id` | | Exact task-adapter binding override |
| `--objective-direction` | | `maximize` or `minimize` |

```bash
kapso evolve --goal "..." --output ./runs/task-001 \
  --config ./runtime.yaml --mode POSTTRAIN --coding-agent codex \
  --launch-inputs ./launch-inputs.json
```

### Fresh-launch JSON

The file is a closed object containing `task_context_request`,
`starting_artifacts`, `dependency_runtime_contract`, and
`budget_fidelity_envelope`. Each artifact contains only `source` and
`mount_path`; relative sources resolve against the JSON file.

### List Commands

| Option | Description |
|--------|-------------|
| `--list-agents` | List available coding agents |

```bash
kapso --list-agents
```

## Examples

### Simple Usage

```bash
kapso evolve \
    --goal "Build a random forest classifier for the Iris dataset" \
    --output ./runs/iris --config ./runtime.yaml \
    --launch-inputs ./iris-launch.json
```

### Resume

```bash
kapso evolve \
    --goal-file problem.txt --output ./runs/task-001 \
    --config ./runtime.yaml --resume
```

## Environment Variables

The CLI loads environment variables from `.env`:

```bash
OPENAI_API_KEY=your-openai-api-key
GOOGLE_API_KEY=your-google-api-key
ANTHROPIC_API_KEY=your-anthropic-api-key
```

## Available Coding Agents

```bash
$ kapso --list-agents

Available Coding Agents:
==================================================
  aider: Git-centric pair programming with diff-based editing
  gemini: Google Gemini SDK for code generation
  claude_code: Anthropic Claude Code CLI for complex refactoring
  openhands: OpenHands agent with sandboxed execution
```

## Exit Codes

| Code | Meaning |
|------|---------|
| `0` | Success |
| `1` | Error (missing arguments, failed experiment) |

## Tips

<Tip>
**Use `kapso --list-agents`** to discover available coding agents.
</Tip>

<Warning>
**API keys are required**. Set them in `.env` or as environment variables.
</Warning>
