# Evaluation profile

The immutable registered evaluator runs `main.py` in an isolated child, requires positionally aligned finite NumPy vectors for all 19,740 validation and 22,617 test rows, scores all validation rows with RelBench `r2`, `mae`, and `rmse`, and uses raw validation MAE as the search score. The `fraction` and `seed` arguments do not subsample rows. Test labels are absent and test metrics are hidden.

The training set has 151,407 facility rows at 19 annual origins from 2001 through 2019; the official validation and test origins are 2020 and 2021. Validation targets are 47.85% zero, 42.98% one, and 9.17% interior ratios. The exact admissible-analysis query yields 14,164 distinct trial/date events from 14,164 trials with a 40.79% exact-all-significant rate.

For the 2020 validation origin there are 19,740 facilities, 26,475 facility-event edges, and 1,042 reporting trials. Pre-origin facility-trial edges cover 96.22% of event edges; 82.81% of facility labels contain one event and 93.38% contain at most two. Across 2012–2019, visible-edge coverage ranges from 97.75% to 99.14%, the single-event share from 75.69% to 88.49%, and mean event multiplicity from 1.20 to 1.46.

Coverage axes are origin year, zero/sparse/rich facility history, history recency, visible roster size and probability mass, one versus multiple likely reports, trial phase, site count, country, snapshot linkage/direct/abstention status, and text availability. The solution's stated validation one-event share (82.3%) and visible coverage (96.9%) are directionally confirmed; the live exact measurement is 82.81% and 96.22%, respectively, owing to the exact 365-day event window and relation-date filter used here.

The score-bounding artifact is the trial-origin replay matrix and its reporting probabilities: without candidate-trial event recall and calibration, neither exact success prediction nor ratio-median decoding can recover the facility target. Validation is a single temporally shifted origin, so design selection uses historical forward windows and the official score remains report-only.

The READY quarterly artifact contains 706,991 trial-origin pairs and 358,010 replay rows, versus 532,302 and 183,321 in the semiannual incumbent. All 183,321 shared replay rows have identical reporting and exact-success labels. The quarterly feature schema has 183 columns rather than 178 because it includes five registry categorical placeholders; verified snapshot attachment overwrites these placeholders before fitting. Monthly at-risk expansion produces 4,117,586 person-period rows. Positive reports span all 12 bins, with bin counts from 1,866 to 3,661, so neither the front nor back half is negligible.

The rolling facility ruler has 18,997/20,487/20,673 rows at the 2017/2018/2019 origins, with target means 0.50556/0.41769/0.41361. Hyperparameters use 2017-to-2018 transfer and the 2019 origin is held for the most-shifted gate. The official 2020 mean is 0.475, confirming that the single official origin is not representative of the recent training-period level.
