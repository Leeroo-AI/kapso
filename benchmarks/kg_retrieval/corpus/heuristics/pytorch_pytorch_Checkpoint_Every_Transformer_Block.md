== Overview ==

Apply recomputation at the granularity of whole transformer blocks, which keeps the added forward cost near one third while removing most stored intermediate tensors.

=== Description ===

Wrapping each attention-plus-feed-forward block as one recomputation unit stores only the block inputs. Finer units save little extra memory but repeat more work; coarser units hold too much at once.

=== Usage ===

Choose this granularity first when enabling recomputation on a transformer.

== The Insight (Rule of Thumb) ==

Treat one transformer block as one unit. Expect step time to rise by roughly 20 to 35 percent and activation memory to fall to about the inputs of the blocks plus one block's worth of intermediates.

== Reasoning ==

Inside a block, the attention scores and feed-forward intermediates dominate the stored tensors, and they are all regenerated by one local forward pass.
